## Java Console Calculator
## Description

-I built this Java Console Calculator to practice basic Java concepts like methods, loops, user input, and exception handling. The program performs Addition, Subtraction, Multiplication, and Division, using modular methods and handles divide-by-zero cases. It allows continuous calculations until the user exits.

## What I Did
-Created methods for each arithmetic operation.

-Used Scanner for user input.

-Implemented a loop-based menu for repeated calculations.

-Handled invalid inputs like divide-by-zero.

-Practiced Java coding structure and logic flow.

##Technologies Used
-Java (JDK 8+)
-Git & GitHub
-Command Prompt / Terminal
