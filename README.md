## Project Overview
-This is a Java Console Calculator project I developed using Eclipse IDE. The calculator performs Addition, Subtraction, Multiplication,
and Division by taking user inputs via console. It uses methods for modular operations, loops for continuous calculations, and handles invalid scenarios like division by zero gracefully.

## What I Did
-Developed a console-based calculator application in Java.

-Created separate methods for Addition, Subtraction, Multiplication, and Division.

-Used Scanner class to take user inputs (numbers and choices).

-Implemented a while loop to perform continuous operations until the user selects Exit.

-Handled division-by-zero cases with an error message.

-Followed a clean modular code structure using methods and switch-case.

-Tested and executed the program using Eclipse IDE (Java Perspective).

## How to Run
-Open Eclipse IDE.

-Create a new Java Project and Package (e.g., Calculator).

-Create a Java Class file named Calculator_task1.java and paste the code.

-Run the program.

-Follow the console instructions to perform calculations.
